# Disk Space Download v2

Personal-use static link helper for DiskWala share links.

- Validates the DiskWala `/app/FILE_ID` URL format.
- Links to Diskwaala's online preview page for available metadata and supported next steps.
- Links to the original DiskWala app URL.

This static page does not perform direct media extraction. Direct browser downloads require an official/authorized download endpoint or API. It does not bypass access controls, app restrictions, subscriptions, or DRM.

Deploy by replacing the repository's `index.html` and committing to the Pages branch.
