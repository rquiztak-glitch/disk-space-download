# Disk Space Download

A standalone first-version landing page for the independent Disk Space Download project.

## Run locally
Open `index.html` in a modern browser.

## Current behavior
- Accepts an HTTP(S) link.
- Recognizes common direct video-file URLs (MP4, WebM, MOV, M4V, OGV) and offers a download link.
- For DiskWala app/share pages, explains that an approved direct-download endpoint or API integration is still required.

This starter does not bypass authentication, paid access, DRM, or platform restrictions. Do not publish it as a working DiskWala downloader until an authorized integration is implemented and tested.
